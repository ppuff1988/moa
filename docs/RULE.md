# 🎯 遊戲概述

《古董局中局》是一款以古董鑑定為主題的推理遊戲，與狼人殺等遊戲有本質差異。

## 🏛️ 遊戲結構

### **核心遊戲流程**

```
1. 房間創建 → 2. 玩家加入(6-8人) → 3. 角色分配 →
4. 三輪鑑寶遊戲 → 5. 鑑人階段 → 6. 結果公佈
```

### **重要：固定3輪結構**

- ✅ **3輪鑑寶** (不是10回合！)
- ✅ **每輪包含**：文物配置 → 行動技能 → 發言討論 → 投票統計 → 結果公佈
- ✅ **3輪結束後**：進入鑑人階段

## 👥 玩家與角色

### **玩家人數限制**

- **最少**: 6人
- **最多**: 8人
- **7人遊戲**: 排除姬云浮
- **6人遊戲**: 排除鄭國渠和姬云浮

### **角色陣營分配**

#### **好人陣營 (許愿陣營)**

1. **許愿** - 核心角色
2. **黃煙煙**
3. **方震**
4. **木戶加奈**
5. **姬云浮** (8人遊戲)

#### **壞人陣營 (老朝奉陣營)**

1. **老朝奉** - BOSS角色
2. **鄭國渠** (7-8人遊戲)
3. **藥不然** - 干擾角色

## 🏺 遊戲元素

### **十二生肖獸首**

- **總計**: 12個獸首（鼠、牛、虎、兔、龍、蛇、馬、羊、猴、雞、狗、豬）
- **真偽配置**: 每局隨機6真6假
- **每輪選擇**: 從12個中隨機選4個進行鑑定

### **玩家顏色**

8種顏色可選：紅、橙、黃、綠、藍、紫、黑、白

## 🎲 遊戲機制

### **每輪遊戲階段**

1. **文物配置階段** - 隨機選擇4件獸首
2. **行動與技能階段** - 玩家依序行動並使用角色技能
3. **發言討論階段** - 開放討論與推理
4. **投票統計階段** - 依房間設定由房主統計，或由所有玩家線上提交籌碼後自動統計
5. **結果公佈階段** - 公佈該輪結果和得分

### **投票模式**

房主建立房間時可選擇是否開啟「線上投票」。此設定預設關閉、建立後不可變更，並且與自動分派角色及顏色的設定互相獨立。

#### **房主計票（預設）**

- 由房主輸入各獸首的總票數。
- 其他玩家等待房主完成統計。

#### **線上投票**

- 房主與所有玩家都必須自行提交投票，沒有代投或強制略過機制。
- 每位玩家每輪獲得 2 枚新籌碼，可逐枚自由分配給當輪 4 個獸首。
- 第一、二輪可投入任意數量（包含 0）；未使用籌碼會累積到下一輪。
- 玩家提交後不可取消或修改。
- 投票進行中只公開已提交玩家的顏色，不公開即時票數或投票目標。
- 全員提交後，系統自動公布 4 個獸首的總票數，以及各玩家顏色投入的籌碼數。
- 進行中只在玩家明確按下「離開房間」時，將玩家標記為 `left` 並移除目前房間資格；手機縮小、背景休眠、網路短暫中斷或關閉其中一個分頁，都只代表暫時斷線，不顯示離線提醒，也不暫停遊戲。
- 明確離開房間後不再顯示「回到房間」；只要仍有房間成員，遊戲會等待離房玩家重新輸入房號與密碼加入，不設定離房期限，也不因部分玩家離房而結束。若所有玩家都明確離房，未完成遊戲會自動標記為 `terminated`，無法再加入。
- 玩家重新加入房間後清除 `left` 狀態並恢復遊戲；若線上投票尚未完成，只有明確離開的玩家重新加入後才會公布結果。
- 遊戲進行中的離房紀錄會設定 `left_at`；全員離房終止時保留玩家、固定座位、行動、投票與私人筆記。已完成的 `finished` 遊戲維持完成狀態，暫時斷線不觸發終止。
- 第三輪必須將所有累積剩餘籌碼投出，否則無法提交。
- 同票時依十二生肖順序（鼠至豬）決定排名；全員投入 0 枚時亦同。
- 第一名真偽維持不公開，第二名公布真偽。

### **行動順序機制**

- **首輪**: 系統隨機選擇起始玩家
- **傳遞**: 行動玩家選擇下一位行動者
- **藥不然偷襲**: 被偷襲玩家下一輪無法行動，但可選擇下一位行動者
- **標記保持**: 最後行動的玩家保留標記，成為下一輪首位行動者

### **固定座位與發言討論**

- 建房時選擇「隨機座位」（預設，適合線上）或「依現場座位」（房主排列），與線上投票、自動選角分開設定。
- 隨機模式在開局時排出一圈；現場模式由房主在大廳按左手方向排列所有玩家並儲存，最後一位接回第一位。每位玩家可查看自己的左右鄰居核對。
- 玩家名單改變時，現場模式須重新確認完整座位。開局後三輪固定，重新加入保留原位；首位行動者仍另外隨機選出。
- 每輪最後一位玩家行動結束後，由他的左鄰第一個發言，沿固定座位依序繞一圈，最後行動者最後發言。
- 遊戲顯示整輪發言順序與實際行動順位，不追蹤目前發言者。玩家使用外部語音或當面討論，完成後由房主開始投票。

### **私人發言筆記**

- 每位玩家自行記錄，只有本人可讀寫；房主也無法查看其他人的筆記。
- 每位玩家每輪可手動標記「偏好人／未判斷／偏壞人」，預設未判斷。標記僅為本人的陣營推測，與角色真實身分、玩家顏色及獸首說法無關；各輪分別保存，切換回合可回看當時的判斷。
- 可從獸首選單記錄「真／偽／無法鑑定／被攻擊（無法鑑定）」，未填時為「未記錄」，另有最多 500 字備註。
- 被攻擊代表整輪無法鑑定，選取後會清除該玩家本輪獸首說法、統一標示被攻擊，備註保留；改選其他狀態或清除紀錄會取消整輪被攻擊。
- 預設按發言順序列出玩家，可切換依行動排序或按獸首對照。兩個順位分開標示，供玩家自行推敲說法真假。
- 筆記不代表系統認定的真偽或攻擊結果；「我的鑑定」另顯示本人實際取得的結果。
- 已儲存筆記可在重新整理、投票與後續回合查閱。遊戲中可編輯已進入討論的回合，結束後僅供回看。
- 儲存失敗可重試；同帳號多個分頁修改同一筆時，需選擇使用雲端版本或保留本次修改。
- 舊局若沒有座位資料，仍可依行動順序記錄，不推測發言順序。

### **勝利條件與計分**

#### **許愿陣營計分規則**

- 每選中1件真品文物 = +1分
- 鑑人階段正確找出老朝奉 = +1分
- 老朝奉未找出許愿身份 = +2分
- 藥不然未找出方震身份 = +1分

#### **勝利判定**

- **許愿陣營勝利**: 總分 ≥ 6分
- **老朝奉陣營勝利**: 許愿陣營 < 6分
